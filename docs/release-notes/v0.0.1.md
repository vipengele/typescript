# v0.0.1

First published release of the vipengele TypeScript framework.

## core

- `@vipengele/ts-core-common` — `VipengeleError`, the abstract base every framework error
  extends, and `Numeric.parse`/`tryParse`/`format` under the `./types/numeric` sub-path for
  locale-aware numeric parsing and formatting.
- `@vipengele/ts-core-redaction` — package scaffold, no public API yet.
- `@vipengele/ts-core-observability` — package scaffold for the logger (`./logger`) and error
  reporter (`./errors`) entry points, no public API yet.

## ts

- `@vipengele/ts` — package scaffold for the framework's batteries-included umbrella package, no
  public API yet.
