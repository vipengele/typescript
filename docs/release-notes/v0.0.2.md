# v0.0.2

The first release with a working public API in every package but the logger. No breaking changes:
every export of v0.0.1 is unchanged.

## core

- `@vipengele/ts-core-common`
  - `./context` — `createAsyncContextStore`, a value carried across an async call chain. It picks
    a carrier in a fixed order — `AsyncLocalStorage`, then `AsyncContext.Variable`, then a
    synchronous stack — and keeps its state behind a `globalThis` registry so dual-resolved copies
    of the package share one store.
  - `./scope` — `Scope`, the ambient context tree the logger and error reporter read attributes
    from (`current`, `propagate`, `inherit`, `isolated`, `useCarrier`), with the `@isolatedScope`
    and `@scoped` method decorators, which work under both the standard and the legacy
    (`experimentalDecorators`) dialect. The root scope holds the reserved `Resource` keys
    (`service.name`, `service.version`, `deployment.environment.name`, `process.runtime.name`);
    writing one elsewhere throws a `ReservedScopeKeyError`, checked with `isReservedScopeKeyError`.
  - `./attributes` — `normalizeAttributes`, which turns an attribute input into a flat, JSON-safe
    `Attributes` record, and the `Attributes`, `AttributesInput` and `AttributeValue` types.
  - `./serialization` — `toJsonSafe`, a bounded JSON-safe serializer, and `serializeError`, which
    walks a thrown value's whole `cause`/`errors` chain into a `SerializedError`.
  - Root — the `Level` (`"trace"` through `"fatal"`) and `Threshold` (`Level | "off"`) types, plus
    the same `normalizeAttributes`, `toJsonSafe` and `serializeError` exports.
- `@vipengele/ts-core-redaction` — `redact`, which replaces the values of sensitive keys in a
  structured value. It takes a `RedactionPolicy` of `KeyMatcher` rules, honours depth and size
  limits through `RedactOptions`, and substitutes a `Replacement`.
- `@vipengele/ts-core-observability` — the `./errors` entry point: `createReporter` builds a
  `Reporter` from a `ReporterBuilder`. `captureException` and `captureMessage` run each event
  through a five-stage pipeline (normalize, enrich, processors, filter, transport) and hand the
  survivor to a `Transport`, whose `send` returns at once and never throws. `createConsoleTransport`
  and `createTestTransport` are the built-in transports. The `./logger` entry point is still a
  scaffold with no public API.

## ts

- `@vipengele/ts` — depends on `@vipengele/ts-core-common` and `@vipengele/ts-core-redaction`, and
  re-exports `Numeric`, `Scope`, `normalizeAttributes` (with its types), `VipengeleError`, and
  `redact` (with `RedactionPolicy`, `KeyMatcher`, `RedactOptions` and `Replacement`).

## Upgrading

Nothing to do: install `0.0.2` of any package. `@vipengele/ts` pins the two core packages it
depends on at exactly `0.0.2`.
