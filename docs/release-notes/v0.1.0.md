# v0.1.0

The first release with a public API in every package, the logger included. It carries two breaking
changes, both marked below.

## Breaking

- **`Numeric` takes a `Locale`, not a string tag.** `Numeric.parse`, `Numeric.tryParse` and
  `Numeric.format` accept a `Locale` from `@vipengele/ts-core-common/locale` (re-exported by
  `@vipengele/ts`). A malformed tag is now rejected once, by `new Locale(tag)`, with a `RangeError`,
  rather than by each call. Omitting the locale still means `Locale.default()`.

  ```ts
  // before
  Numeric.format(1234.5, "de-DE");
  Numeric.parse("1.234,5", "de-DE");

  // after
  import { Locale, Numeric } from "@vipengele/ts";

  const de = new Locale("de-DE");
  Numeric.format(1234.5, de);
  Numeric.parse("1.234,5", de);
  ```

- **`redact` is bounded by default.** `RedactOptions` gains `maxDepth` (6), `maxBreadth` (100) and
  `maxStringLength` (8192). A container nested deeper than `maxDepth` becomes `"[Truncated]"`,
  entries beyond `maxBreadth` collapse into one `"[Truncated: N more]"` marker, and a longer string
  is cut and suffixed with `"…[truncated]"`. A value under a matched key is still replaced at any
  depth. Pass `Infinity` to turn a limit off.

## core

- `@vipengele/ts-core-common`
  - `./types/date-time` — `LocalDate`, `LocalTime` and `LocalDateTime`: validated, immutable,
    zoneless civil values; `Instant`, a point on the UTC timeline; `ZoneId`, a named time zone; and
    `ZonedDateTime`, a date and time of day in a zone.
    - `of` (and `LocalDateTime.ofFields`) validates its fields and throws an
      `InvalidDateTimeError`; `parse` reads ISO 8601 (`2024-03-09`, `15:30:45`,
      `2024-03-09T15:30`, and a fraction of one to nine digits such as `15:30:45.123456789`) and throws
      a `DateTimeParseError`; `tryParse` returns a `DateTimeTryParseResult`. `toString` writes ISO
      8601, with a fraction only when the nanosecond is non-zero, as 3, 6 or 9 digits. The guards are `isInvalidDateTimeError`
      and `isDateTimeParseError`.
    - `LocalDate` and `LocalDateTime` add days and months (`plusDays`, `minusDays`, `plusMonths`,
      `minusMonths`, clamping to the end of a shorter month); `LocalDate` also has `dayOfWeek` and
      `lengthOfMonth`. All three have `compare` and `equals`.
    - `LocalTime` and `LocalDateTime` hold a `nanosecond` (0 to 999,999,999), the last argument of
      `LocalTime.of` and `LocalDateTime.ofFields`.
    - `now(clock?)` reads the local civil value from a `Clock`, `systemClock` by default, floored
      to the microsecond.
    - `format(locale?)`, `parseLocalized(str, locale?)` and `tryParseLocalized(str, locale?)` write
      and read a locale's own numeric pattern (`03/09/2024` in `en-US`, `09.03.2024` in `de-DE`). A
      time or date-time is localized to hour and minute only, so parsing one gives second and
      nanosecond `0`. The locale's hour cycle is honoured: a 12-hour locale prints a day-period
      marker, and a 24-hour one never prints hour 24. The pattern is read from `Intl`, always in
      the Gregorian calendar and ASCII digits.
    - `LocalDate#segments(locale?)` returns the pattern as `DateSegment[]`, each a `year`, `month`,
      `day` or `literal` with its `value`, for a date input that lays out its own fields.
    - `Instant` holds epoch seconds and a nanosecond within `Date`'s ±8.64e15 ms range:
      `ofEpochSecond`, `ofEpochMilli` and `now(clock?)` construct one, `toEpochSecond`,
      `nanosecond` and `toEpochMilli` read it, and `plusSeconds`, `plusMillis`, `plusNanos` and their
      `minus` forms do exact arithmetic. `parse` and `toString` read and write ISO 8601 in UTC with a
      literal `Z`, using a signed six-digit year outside 0000 to 9999; `compare` and `equals` order
      them.
    - `ZoneId.of(id)` reads a case-insensitive IANA zone name and throws an `UnknownZoneError`
      (`isUnknownZoneError`) for an unknown name or a UTC-offset id such as `+05:30`. `id` is
      `Intl`'s canonical spelling, which depends on the runtime's ICU version. `systemDefault()`
      reads the runtime's zone, and `offsetSecondsAt(instant)` returns the offset in whole seconds.
    - `ZonedDateTime` holds a date, a time of day and the offset they read in a `ZoneId`. It is
      built by `ZonedDateTime.of`, `LocalDateTime#atZone`, `LocalDate#atStartOfDay` and
      `Instant#atZone`. A time the zone skips or reads twice is settled by the `disambiguation`
      option: `compatible` (the default, as in `java.time`), `earlier`, `later` or `reject`, which
      throws a `ZoneResolutionError` (`isZoneResolutionError`). `plusDays` and `plusMonths` (and
      their `minus` forms) move the local date and re-resolve it, so a day across a spring-forward is
      23 hours; `plusHours` through `plusNanos` move the instant exactly. `parse`, `tryParse` and
      `toString` use the strict ISO form `2026-10-01T14:30+02:00[Europe/Berlin]`, where the offset
      must be one the zone reads. `ZonedDateTimeOptions` and `Disambiguation` are exported.
  - `./locale` — `Locale`, a validated BCP 47 tag with month and weekday names, hour cycle and
    first day of the week, with `HourCycle`, `IsoWeekday` and `NameStyle`.
  - `./runtime` — `detectRuntime` and `detectCapability`. Shipped source no longer imports a
    `node:` specifier outside `import type`; a Node built-in is reached through
    `process.getBuiltinModule`.
  - `./scope` — `Scope.setResource(partial)` merges the four Resource keys into the realm's one root;
    `Scope.setUser`, `Scope.setTag` and `Scope.setContext` write flat dotted keys (`user.id`, `region`,
    `cart.items`) to the current scope, and a Resource key there throws `ReservedScopeKeyError`.
  - Root — `SEVERITY_NUMBERS`, `SeverityNumber`, `isLevel`, and the `Clock` type with `systemClock`.
- `@vipengele/ts-core-redaction`
  - `secretKeys`, a frozen preset policy, and `composePolicies`, which combines policies;
    `RedactionPolicy` supports `except` carve-outs and `{ segments }` matching.
  - `redactUrl`, `redactQueryString` and `redactHeaders` redact text-shaped values, with
    `RedactStringOptions`, `HeaderRecord` and `HeaderTuples`.
  - `valueDetectors` (`jwt`, `bearerToken`, `creditCard`, `email`, `awsAccessKey`, `githubToken`,
    `stripeKey`) are opt-in detectors that redact a secret by the shape of its value.
  - `maskKeepLast(keep)` keeps the last characters behind a fixed four-character mask, and
    `pseudonymize({ key })` replaces a value with a stable HMAC-SHA-256 token. Both are
    `Replacement`s for the `replacement` option of `redact`, `redactUrl`, `redactQueryString` and
    `redactHeaders`.
- `@vipengele/ts-core-observability`
  - `./logger` — the `Logging` facade configures the default `LoggerProvider` through a layered
    builder or a spec string (`parseSpec`). Loggers are named by category, and a category with
    nothing configured resolves to `warn`. A bad level given in code throws `LoggingConfigError`
    (`isLoggingConfigError`); a bad entry in a spec string is skipped with a warning. Loggers emit
    structured `LogRecord`s to `Sink`s.
  - `./errors` — `ReporterBuilder` takes integrations, and `globalHandlers` installs the global
    error and unhandled-rejection handlers behind a required `ExitPolicy`. An event's stack is
    parsed into `StackFrame`s, with in-app frames marked. An event's attributes carry the scope
    chain it was captured in, and each event is redacted with `secretKeys` unless
    `ReporterBuilder#redaction` sets a policy or `null`. `Transport.send(event, resource)` receives
    the frozen `Resource` read for that event as its second argument; an existing `Transport` that
    ignores it keeps working.

## ts

- `@vipengele/ts` re-exports, alongside what `v0.0.2` listed:
  - `Locale`, with `HourCycle`, `IsoWeekday` and `NameStyle`.
  - `LocalDate`, `LocalTime`, `LocalDateTime`, `Instant`, `ZoneId`, `ZonedDateTime`,
    `DateTimeParseError`, `InvalidDateTimeError`, `UnknownZoneError`, `ZoneResolutionError`,
    `isDateTimeParseError`, `isInvalidDateTimeError`, `isUnknownZoneError` and
    `isZoneResolutionError`, with the `DateSegment`, `DateSegmentType`, `DateTimeTryParseResult`,
    `Disambiguation`, `IsoDayOfWeek` and `ZonedDateTimeOptions` types.
  - `secretKeys`, `composePolicies`, `redactUrl`, `redactQueryString`, `redactHeaders`,
    `maskKeepLast`, `pseudonymize` and the value detectors, with `RedactStringOptions`,
    `MaskOptions` and `PseudonymizeOptions`.

## Upgrading

Install `0.1.0` of any package; `@vipengele/ts` pins the two core packages it depends on at exactly
`0.1.0`. Wrap every string locale tag passed to `Numeric` in `new Locale(tag)`, and check that
nothing relied on `redact` walking past the default depth, breadth or string-length limits.
