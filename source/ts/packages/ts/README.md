# @vipengele/ts

The batteries-included umbrella package of the vipengele TypeScript framework. It reserves the
`@vipengele/ts` name and package shape; it carries no functionality of its own and will re-export
the `@vipengele/ts-core-*` packages once they have a first release.

```sh
pnpm add @vipengele/ts
```

Runs in the browser and in Node 24+. ESM only, side-effect free.
